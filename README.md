Kisaan – AI Based Smart Farming App

Project Status

🚧 This project is currently under active development. New features, improvements, and optimizations are continuously being added.

Overview

Kisaan is an Android application designed to support farmers through digital technology and AI-powered solutions. The platform aims to provide farming assistance, agricultural information, market updates, weather forecasting, and smart services in a single application.

Key Features

AI-Based Plant Disease Detection

The application includes a machine learning-based plant disease detection system developed using Scikit-learn. The model has been trained on a large collection of plant leaf images covering multiple plant species and disease categories.

Key capabilities include:

- Plant disease identification through image analysis.
- Support for multiple plant varieties and disease categories.
- Recognition of unsupported or unknown inputs.
- If an uploaded image does not contain a valid leaf or belongs to an unsupported category, the model can respond with messages such as "Not a Leaf" or indicate that plant data is unavailable.

This feature helps farmers identify crop health issues at an early stage and make informed decisions.

Kisaan Doot

Kisaan Doot is a field-support service where agents can visit farms, understand farmers' problems, and provide assistance and guidance.

Market Agent

The application includes a market information service that helps farmers stay updated with agricultural market prices and trends from agricultural produce markets.

Agricultural Partnership

The project includes collaboration and sponsorship support from a real agricultural center, helping improve the practical usefulness of the platform.

Weather Updates

Farmers can access weather information directly within the application to support farming decisions.

Agricultural News

The application provides agriculture-focused news and updates relevant to farmers.

Government Schemes

Users can access information about government schemes and benefits available for farmers.

Feedback System

Farmers can submit feedback regarding agents and services available through the platform.

User Authentication

The application includes user registration and login functionality.

Vision

The goal of Kisaan is to bridge the gap between farmers and technology by providing practical, AI-powered, and information-driven farming solutions through a single platform. The project aims to make farming smarter, more accessible, and technology-driven for the agricultural community.
